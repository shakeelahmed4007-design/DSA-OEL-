# Hospital Emergency Management System

Frontend-only DSA Lab project built with React, Vite, JavaScript, HTML/CSS.

## Run
```bash
npm install
npm run dev
```

## DSA Concepts
Queue, Priority Queue, Stack, Linked List concept, Graph, BFS, DFS, Dijkstra, Linear Search, Binary Search, Bubble Sort, Selection Sort and Insertion Sort.

Data is stored in browser LocalStorage. No backend, database, Firebase or Supabase is used.
